## The outcome

Control OpenClaw model spend without treating every task like it needs the biggest model. This skill covers task-based model routing, presets, budget guidance, and a savings tracker.

## What you get

A practical routing plan that separates cheap routine work from the jobs where stronger models earn their keep.

## Quick start

1. Install the ClawHub skill: `openclaw-cost-optimizer`
2. Run `/cost-optimizer`
3. Share your current providers, models, workload, and budget. Ask for an audit before changing routing.
4. Review the output before publishing, sending, or changing live systems.

## A useful first prompt

```text
Use /cost-optimizer with me. First ask only for the information you need to produce a reliable result. Do not invent missing facts, claims, prices, owners, or deadlines. Show me the draft before anything is published or sent.
```
